# Connector brand assets

Official, unmodified SVG marks downloaded on 2026-10-06:

- `github.svg`: `GitHub Logos/SVG/GitHub_Invertocat_Black.svg` from the [GitHub brand toolkit](https://brand.github.com/foundations/logo), [asset archive](https://brand.github.com/GitHub_Logos.zip).
- `linear.svg`: `logo-dark.svg` from [Linear's brand guidelines](https://linear.app/brand), [asset archive](https://static.linear.app/design-assets/Linear-Brand-Assets.zip?v=3).

These marks belong to their respective owners and identify the integrations.

For a new connector, place its brand mark here and set `icon` in `lib/connectors/catalog.ts` to its public path. The shared `ConnectorIcon` component handles sizing and a light background for contrast in either theme. Keep the provider name alongside the decorative icon for accessibility.
